# Stage 8 — Final Five Council Release

## Purpose

Stage 8 makes the Five Council the final affirmative gate for every consequential Dominion release.

The enforced order is:

```text
technical readiness
→ human scope authorization
→ five independent Council reviews
→ unanimous final Council decision
→ release only within the approved scope
```

The Human Overseer remains the accountable authority and may revoke, suspend, or emergency-stop a released action at any time. No additional affirmative click is required after the Council because the Council is the last positive release gate. Law or Security vetoes cannot be overridden by an agent or by ordinary workflow automation.

## Consequential release classes

The final gate applies to trial activation, revenue-wave activation, production deployment, external publication, pricing changes, customer or claimant contact, money movement, live trading, KDP publication, Wix go-live, external data distribution, agent promotion, and main-branch release decisions.

## Similarweb target approval

The Human Overseer approved the fifteen-domain target manifest. Five independent Council records then reviewed that narrow approval scope and unanimously approved it with conditions.

The approved scope is only:

```text
target_manifest_approval_only
```

It does not start the trial, access an account, authorize billing, consume credits, permit browser scraping, distribute Similarweb data, verify revenue, or authorize external execution.

A future trial activation requires a new release request after live account capabilities, billing terms, export limits, API entitlement, storage readiness, and terms compliance are recorded. That future activation request must again pass Human Overseer scope authorization followed by the Five Council as the final gate.
