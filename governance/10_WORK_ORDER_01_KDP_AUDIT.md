## PHASE 1 — INVENTORY TRUTH (Day 1)
Log into KDP. For every title, record with truth state:

| Field | What to capture |
|---|---|
| Title / subtitle | Exact as listed |
| ASIN | Per format |
| Formats live | Kindle / paperback / hardcover |
| Status | Live, draft, blocked, unpublished |
| List price | Per format, per marketplace |
| Royalty rate | 35% or 70% — **flag any 35% that could be 70%** |
| KDP Select | Enrolled or not |
| Categories | All assigned |
| Keywords | All 7 slots — flag any empty |
| Series linkage | Linked or orphaned |
| A+ Content | Present or absent |
| Reviews | Count and average |
| Lifetime sales | Units and royalties to date |
| Cover | Screenshot for assessment |

**Deliverable:** one table, six-plus rows, every cell VERIFIED or UNKNOWN. No assumptions.

## PHASE 2 — DIAGNOSIS (Day 2)
Rank every title by fixable gap. The highest-leverage fixes, in order:
1. **Royalty rate** — a title at 35% that qualifies for 70% is losing half of every sale. Fix first.
2. **Empty keyword slots** — seven free discovery slots; empty ones are invisible shelf space.
3. **Wrong or default categories** — a title in a broad category competes with everything; a well-chosen niche category can rank on low volume.
4. **Weak description** — most common conversion killer. Hook, benefit, structure, no wall of text.
5. **Orphaned titles** — related books not linked as a series lose all cross-sell.
6. **No A+ Content** — free, and it lifts conversion.
7. **Cover** — hardest and most expensive to fix; assess honestly, defer if it requires spend.

**Deliverable:** ranked fix list, effort vs. impact, cost stated ($0 for all of the above except cover).

## PHASE 3 — EXECUTE (Days 3–5)
Apply fixes **one title at a time**, highest-leverage first. Record before/after for every change — this is the learning loop (Amendment 03 §3) and the baseline for measuring what worked.

**One variable per title where possible.** Changing keywords, category, price, and description simultaneously makes the result unattributable.
