# Registry Evidence Notes

The current seed records only services and ports previously observed in the production ecosystem audit. It does not claim the inventory is complete.

Unresolved fields must not be silently filled:

- `owner_agent_id`
- `repository_path`
- `rollback_reference`
- complete dependency graph
- complete scheduler inventory
- data classification
- secret access boundaries

These must be populated from fresh production evidence and matched against repository governance before promotion or runtime modification.
