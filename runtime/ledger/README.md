# Runtime evidence ledger

Local JSONL ledgers generated by the control-plane CLI belong here and are ignored by Git.

The application hash chain detects modification, deletion, reordering, and broken linkage. Production storage must additionally enforce access control, backups, retention, and write-once or object-lock behavior where required.

No secret values, private customer data, credentials, or raw restricted payloads may be written to this ledger. Store references and approved evidence identifiers instead.
